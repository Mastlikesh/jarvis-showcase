# 🤖 J.A.R.V.I.S. — My Personal Voice Assistant

> Say **"Hey Jarvis"** and it wakes up, listens, and gives me a full briefing on what I missed: mails, calls and notifications.

An Iron Man–style voice assistant I'm building and running on my own laptop, with a holographic HUD interface and Claude Code as its brain.

---

## ✨ What it does

- 🎙️ **Wake word + voice conversation**: "Hey Jarvis" to wake it, then just talk
- 📬 **Daily briefing**: reads out what happened in Gmail, calls and notifications
- 📱 **Opens apps on command**: *"Hey Jarvis, open WhatsApp and check who DM'd me"*
- 🎬 **Learns from reels**: watches Instagram reels about Claude / Claude Code, understands the steps, and can apply them to my projects; I can ask it about any reel I've watched later
- 🌐 **Does real tasks**: web search, browser control, reading mail aloud
- 🖐️ **Holographic HUD**: animated 3D interface with hand-gesture control

## 🛠️ Tech stack

| Part | Tech |
|------|------|
| Interface (the "face") | React, Vite, Three.js, custom GLSL shaders |
| Brain | Claude Code (headless) |
| Bridge | Node.js |
| Voice | Browser speech APIs (optional ElevenLabs) |
